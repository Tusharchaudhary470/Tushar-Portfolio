## 🚀 Key Features

- **Cyberpunk / Anime Magazine Hero:** High-contrast crimson red (`#DC1428`) theme featuring a 3D illustrated avatar overlapping bold condensed typography (`FULLSTACK DEVELOPER`).
- **First-Visit Animated Splash Screen:** Smooth `00% -> 100%` loading counter with curtain reveal, guarded by `sessionStorage` to avoid reload flicker.
- **Floating Capsule Header & Dock:** Pinned floating capsule navbar with smooth scroll triggers and a persistent bottom action dock with quick links (Email, Phone, GitHub, LinkedIn, Back-to-Top).
- **Featured Flagship Showcase (Rosterly):** 
  - Comprehensive esports management SaaS with real production dashboard screenshots.
  - Interactive deep-dive architecture modal showcasing the tactical SVG strat board, Euclidean distance algorithms, dual-state escrow engine, and enterprise RBAC.
- **Single-Glance Tech Stack:** 16 official vector brand icons across Frontend, Backend, Database, and DevOps—instantly reviewable in a single look without waiting for marquees.
- **Responsive Engineering:** Fully optimized for mobile screens using bounded frame architecture and fluid typography.

---

## 💻 Tech Stack

- **Frontend:** React 19, TypeScript, Tailwind CSS v4, Vite, Lucide Icons
- **Animation & Motion:** CSS transitions, custom scroll-reveal hooks (`IntersectionObserver`)
- **Deployment:** Vercel / Render

## 🛠️ Local Development

Clone the repository and install dependencies:

```bash
git clone https://github.com/Tusharchaudhary470/Tushar-Portfolio.git
cd Tushar-Portfolio
npm install
```

Start the local development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
